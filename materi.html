Feedforward Neural Networks

Composite function

  • A composite function is a function formed by applying one function to the output of another function.
  • Let f(x) = x2 and g(x) = x + 1, then the composite function

    y = (f ∘ g)(x) = f(g(x)) = (x + 1)2

  • More compositions:

    x → f1(x) → f2(f1(x)) → f3(f2(f1(x)))

Feedforward neural networks

  • A feedforward neural network is a composite function of multiple variables, consisting of many linear and nonlinear functions.
  • w: weight, b: bias.
  • Sometimes, all of them are called weights or trainable parameters.
  • Feedforward neural network = multilayer perceptron.
  • Feedforward neural network = fully connected network.

Layer-wise computation

  • Instead of computing

    y = f(w5f(w1x1 + w2x2 + b1) + w6f(w3x1 + w4x2 + b2) + b3)

  • The above equation can be written as

    h1 = f(w1x1 + w2x2 + b1)

    h2 = f(w3x1 + w4x2 + b2)

    y = f(w5h1 + w6h2 + b3)

    which is a neural network with one hidden layer containing two neurons (or nodes).

Matrix and vector computations are faster

h1 = f(w1x1 + w2x2 + b1)

h2 = f(w3x1 + w4x2 + b2)

y = f(w5h1 + w6h2 + b3)

  • It can be written as H1 = [ h1 h2 ] = f( [ w1 w2 w3 w4 ] [ x1 x2 ] + [ b1 b2 ]) = f( W1 X+ B1 ) y= f( [ w5 w6 ] [ h1 h2 ] + b3 )= f( W2 H1 + B2 )
  • Or H1 =[ h1 h2 ]= f( [ x1 x2 ][ w1 w3 w2 w4 ]+[ b1 b2 ])= f( X W1 + B1 ) y= f( [ h1 h2 ][ w5 w6 ]+ b3 )= f( H1 W2 + B2 )

Differential Equations

Differential equations

  • Ordinary differential equation (ODE). The one-dimensional Bratu equation:

    uxx + Ceu = 0,  x ∈ [0, 1]

    u(0) = 0,  u(1) = 0

  • The objective is to approximate the solution u(x) across the domain.
  • Partial differential equation (PDE). The Burgers equation: ut + u ux − 0.01π uxx =0, x∈ [−1,1], t∈ [0,1],

    u(x, 0) = − sin(πx),

    u(−1, t) = u(1, t) = 0.

  • The objective is to approximate the solution u(x, t) across the domain.

Common solvers/methods

  • Time-independent differential equations, u(x), u(x, y):
    • Finite difference method
    • Finite element method
    • Spectral method
  • Time-dependent differential equations, u(x, t): time integration + spatial derivative/discretization
    • Time integration:
      • Euler method
      • Runge–Kutta method
      • ode45 (MATLAB)
    • Spatial derivative/discretization:
      • Finite difference method
      • Finite element method
      • Spectral method

Physics-Informed Neural Networks (PINNs)

  • PINNs: using a feedforward neural network to approximate the solutions of differential equations.
  • The Burgers equation:

    ut + uux − (0.01/π)uxx = 0,   x ∈ [−1, 1],   t ∈ [0, 1],

    u(x, 0) = −sin(πx),

    u(−1, t) = u(1, t) = 0.

  • The solution is approximated by a continuous neural network function with two hidden layers

    u(x, t, W) = σ(σ([x t]W1 + B1)W2 + B2)W3 + B3,

  • Unknowns: the weights W.

Collocation points and loss function

  • Choose some random/grid interior points: {xki, tki}, k = 1, ..., ni.
  • Choose some random/grid boundary/initial points: {xkb, tkb}, k = 1, ..., nb.
  • Loss function:

    L(W) = MSEi + MSEb

    where the PDE residual is

    MSEi = (1/ni) ∑k=1ni (ut(xki, tki, W) + u(xki, tki, W)ux(xki, tki, W) − (0.01/π)uxx(xki, tki, W))2

    and the boundary/initial residual is

    MSEb = (1/nb) ∑k=1nb (u(xkb, tkb, W) − utrue(xkb, tkb))2

Advantages of PINNs

  • Mesh (or grid)-free
  • Efficient inverse problems (or parameter estimation)
  • Automatic differentiation
  • Unified framework: ODEs, 2D PDEs, 3D PDEs
  • Hard constraint: enforce the initial and boundary conditions directly into the network structure
